# Kit de lancement d'Apidays (Abeil, 2 novembre 2026)

Fichiers prêts à diffuser aux collaborateurs d'Abeil :

- `Apidays-guide-collaborateurs.pdf` : guide de prise en main (création du compte, poser un congé, légende du calendrier, bouton « Votre avis compte », contact : Delphine).
- `qr-apidays.png` / `qr-apidays.svg` : QR code vers `https://apidays-seven.vercel.app` (à scanner depuis un mobile pour ouvrir l'application).

**Si l'adresse de l'application change** (nom de domaine personnalisé), le QR code et le guide sont à régénérer : le QR code encode l'URL en dur, les captures du guide viennent de l'application.

Le guide a été produit en dehors du dépôt (HTML + captures automatiques, Chrome) ; seuls les fichiers finaux sont rangés ici.
